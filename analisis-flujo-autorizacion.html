❌ ¿Por qué NO funciona como debería?

He identificado 5 problemas críticos que impiden el flujo completo:

Problema #1: Modo Edición Incompleto

Ubicación: flujo-autorizacion-mejorado.js línea 266

El código incluye un comentario que dice "Aquí se implementaría la lógica de edición inline". Las celdas de la tabla NO son clickeables.

Impacto: El usuario no puede editar valores presupuestarios.

Problema #2: No se Capturan Cambios

Ubicación: flujo-autorizacion-mejorado.js línea 293

const cambios = this.callbacks.obtenerCambios(); // ← Devuelve undefined

En SUMMARY.html no se pasa el callback obtenerCambios al inicializar FlujoAutorizacion.

Impacto: Los cambios editados en la tabla se pierden.

Problema #3: Endpoint Faltante

Ubicación: src/routes/borradores.js

El flujo intenta hacer GET a /api/borradores/estado pero este endpoint no existe.

Impacto: La UI no puede sincronizar con el estado real del borrador en BD.

Problema #4: Persistencia Silenciosa

Ubicación: borradoresService.js línea 338

if (!presupuesto.length) { return; // ← Falla silenciosa sin error }

Si no hay datos, la función devuelve sin hacer nada. El estado cambia a GUARDADO pero sin datos reales en Firebird.

Impacto: Base de datos inconsistente.

Problema #5: Desintegración de Componentes

El flujo de autorización está en un archivo separado y SUMMARY.html no lo integra correctamente:

  • No hay callbacks para extraer cambios
  • No hay validación de datos antes de guardar
  • No hay feedback visual sobre el estado actual

4 PASOS para solucionar

PASO 1: Implementar Edición en Tabla

Crear: vistas/js/modo-edicion-presupuesto.js

Script que transforma la tabla en editable:

  • Celdas clickeables cuando está en modo edición
  • Inputs para editar valores numéricos
  • Captura automática de cambios
  • Devuelve formato esperado por el flujo

Impacto: El usuario puede editar valores.

PASO 2: Agregar Endpoint Faltante

Modificar: src/routes/borradores.js

Agregar ruta:

router.get('/estado', (req, res) => { // Retorna el estado actual del borrador // Sincroniza UI con base de datos });

Impacto: UI siempre actualizada.

PASO 3: Conectar Todo en SUMMARY.html

Integrar: Script de modo edición + Flujo de autorización

const flujo = new FlujoAutorizacion({ obtenerCambios: () => ModoEdicionPresupuesto.obtenerCambios(), // ... otros callbacks }).init();

Impacto: Todos los componentes trabajan juntos.

PASO 4: Mejorar Validación

Actualizar: src/services/borradoresService.js

Agregar validaciones en persistirEnFirebird:

  • Validar que datos no estén vacíos
  • Registrar logs descriptivos
  • Auditar cada operación

Impacto: Base de datos confiable.

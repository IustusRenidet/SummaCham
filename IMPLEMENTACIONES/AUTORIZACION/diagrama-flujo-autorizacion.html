📋 Flujo de Autorización de Presupuestos

⚠️ Nota importante: Los administradores globales tienen un flujo simplificado que va directo de EDITANDO → APROBADO → GUARDADO, sin pasar por revisión ni autorización.

1. EDITANDO

Descripción: Usuario con permisos de "Cargar y guardar" está editando el presupuesto.

Características:

  • Modo edición activo en la tabla
  • Autocompletado de cuentas activas (STATUS = 'A')
  • Se pueden ingresar valores para cada mes
  • Los cambios se guardan como borrador
Acciones disponibles: ✏️ Editar valores 💾 Guardar borrador 📤 Enviar a revisión ❌ Cancelar
Cargar y guardar
↓

👤 Flujo Normal

2. PENDIENTE

Descripción: Presupuesto enviado para revisión.

El usuario que cargó el presupuesto lo envía para que sea revisado.

Acciones disponibles: ✅ Marcar como revisado ❌ Rechazar 💬 Agregar comentarios
Revisar
↓

3. REVISADO

Descripción: Presupuesto revisado, listo para autorización.

Un usuario con permisos de revisión marcó el presupuesto como correcto.

Acciones disponibles: ✅ Autorizar ❌ Rechazar ↩️ Cancelar revisión
Aprobar
↓

4. APROBADO

Descripción: Presupuesto autorizado, listo para guardar en COI.

Un usuario con permisos de autorización aprobó el presupuesto.

Acciones disponibles: 💾 Guardar en COI ❌ Rechazar
Aprobar

⚡ Flujo Administrador Global

🎯 Flujo simplificado: Los administradores globales omiten los pasos de revisión y autorización. Al enviar el presupuesto, se aprueba automáticamente.

AUTO-APROBADO

Descripción: El sistema aprueba automáticamente el presupuesto.

No requiere revisión ni autorización de otros usuarios.

Acciones disponibles: 💾 Guardar en COI
Admin Global
↓

5. GUARDADO

Descripción: Presupuesto guardado en la base de datos de COI (Firebird).

Proceso:

  • Se insertan/actualizan registros en tabla PRESUPYY (YY = últimos 2 dígitos del año)
  • Columnas: PRESUP01 (Enero), PRESUP02 (Febrero), ..., PRESUP12 (Diciembre)
  • Se notifica a todos los involucrados
  • El flujo termina y el módulo queda disponible para un nuevo ciclo
Estado final: ✓ Proceso completado
⟲

RECHAZADO

Descripción: Presupuesto rechazado, requiere correcciones.

Puede ser rechazado en cualquier etapa (revisión o autorización).

Qué sucede:

  • Se notifica al creador del presupuesto
  • Se incluye el motivo del rechazo en los comentarios
  • El creador puede editar y reenviar
  • El flujo vuelve a empezar desde EDITANDO
Acciones disponibles: ✏️ Editar y reenviar
Cargar y guardar (solo creador)

📊 Resumen de Permisos

Permiso Puede ver estados Acciones permitidas
Cargar y guardar EDITANDO, RECHAZADO, GUARDADO Cargar, editar, enviar a revisión
Revisar PENDIENTE, REVISADO Marcar como revisado, rechazar, cancelar revisión
Aprobar REVISADO, APROBADO Autorizar, rechazar, guardar en COI
Admin Global Todos los estados Todas las acciones, flujo simplificado

🔔 Notificaciones

El sistema envía notificaciones en los siguientes casos:

  • 📤 Envío a revisión: Notifica a usuarios con permiso "Revisar"
  • ✅ Marcado como revisado: Notifica a usuarios con permiso "Aprobar"
  • ✅ Autorización: Notifica a usuarios con permiso "Cargar y guardar"
  • ❌ Rechazo: Notifica al creador del presupuesto
  • 💾 Guardado en COI: Notifica a todos los involucrados

📝 Reglas Importantes

✓ Permitido:
  • Solo un flujo activo por empresa/módulo/año
  • El creador puede editar presupuestos rechazados
  • Administradores ven todos los borradores
  • Un solo usuario con permisos puede avanzar cada etapa
✗ No permitido:
  • Modificar borrador que no esté en EDITANDO o RECHAZADO
  • Enviar borrador vacío
  • Guardar en COI sin estar APROBADO
  • Iniciar nuevo flujo si hay uno activo
✅ Mejoras implementadas:
  • Flujo estandarizado con estados claros
  • Visibilidad de borradores según permisos
  • Botones contextuales según etapa
  • Modo edición con autocompletado de cuentas
  • Notificaciones automáticas
  • Panel de comentarios en rechazos
  • Flujo simplificado para administradores
  • Vista de gestión de borradores centralizada
